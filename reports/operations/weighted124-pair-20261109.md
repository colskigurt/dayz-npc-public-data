# 124가중 본 결합 — 포즈 일치와 제한된 실제 표시 확인

## 1. 작업 목표
현재 두64본 파트 합성과124가중 본 결합 모델의 대응 포즈 및 실제 부분 메시 표시를 비교한다. 호스트 축소 연구의 표시 관문이며 게임플레이·비용 시험은 아니다.

## 2. 실제 수행
수정 완료된 명시적 중괄호 하네스와 기존 고정 카메라·Steam 실행기를 재사용했다. 대조군 두 참조 파트를 같은 위치, 결합 후보를 옆 위치에 배치하고124본을 원래 파트0(64개)/파트1(나머지60개)에 대응시켰다. 모든 호스트는 같은 full-native 그래프/Run 명령, AI·루트 이동 없음이다. 하체 관찰을 위해 모두 동일0.7m 높이로 배치하고 카메라 look 높이를1.5m로 맞췄다.
첫 실행에서는 독립 참조 호스트 둘이 밀려 떨어졌다. 이를 후보 표시 실패로 처리하지 않고 기록했다. 다음 실행은 진단 미션에서 세 호스트 모두 dBodySetSolid(false)를 적용하고 종료 때 true 복원을 요청했다. 실제 NPC나 배포 코드의 충돌 정책은 바꾸지 않았다.

## 4. 원인 분석
확인: 현재124개 실제 가중 본 결합 입력은 서버·클라이언트 CPU 포즈를 유지하며 제한된 Run 부분 메시 관찰에서 기존 합성과 대응하는 외형으로 표시됐다. 첫 실행의 상하체 분리는 독립 대조군 호스트의 월드 위치 이탈이었고, non-solid 진단 설정에서 해소됐다.
추정: 이 결과는 더 큰 가중 본 통합을 검토할 근거가 된다. 하지만 CPU 위치 일치와 소수 화면만으로 GPU 스킨의 전체 정밀도나 임의 본 수·모든 동작의 안전성을 입증하지 않는다.
미확인: 전체224가중 본/14클립/실제 충돌 기능/서브골격256경계/생산용 축소 native 골격과의 비용 차이. 비고체 설정의 성능을 실제 NPC 최적화 성과로 취급하지 않는다. 과거의 독립 호스트와 생산 Director의 내부 파트 접촉 관리도 혼동하지 않는다.
