# Days Gone 지붕 호드 비용 계측 — 확인 범위와 한계

## 1. 작업 목표

Days Gone 지붕 고정 호드 장면의 실제 표시 시간과 CPU 스택을 수집하고, 기존 접촉·지지 정적 분석으로 설명 가능한 범위를 확인한다. DayZ 코드 최적화나 엔진 전체 분석은 하지 않는다.

## 2. 실제 수행

사용자 요청으로 카메라만 호드를 향하도록 조정했다. 플레이어 위치는 바뀌지 않았다. 기존 CPU/WPR·PresentMon 하네스와 기존 함수 분류를 재사용했다. CPU와 Present 동시 수집의 불완전한 CSV, 일시정지 조건이 섞인 표시 전용 1차는 제외하고 원문 보존했다. 이후 게임 재개·호드 표시를 직접 확인하고 WPR 없이 표시 전용 20초를 수집했다. 새 바이너리 패치·게임 코드·PBO 수정은 없다.

## 3. 측정 결과

조건: 3440×1440, VSync ON, 등록 300/비사망 296, 지붕 고정, 노클립 OFF. 화면에 296개체 모두 표시되거나 모두 애니메이션 평가된다는 뜻은 아니다. 무적·탄약·노클립 제어 도우미는 실행 상태이며 오버헤드 OFF 대조는 없다.

유효 표시 수집 1회, 993행, 0.214~20.064초. 시작·끝을 제외한 2~18초 800행:

| 지표(ms) | p50 | p95 | p99 |
|---|---:|---:|---:|
| Present 간격 | 19.990 | 24.771 | 27.259 |
| 실제 표시 변경 간격 | 20.006 | 20.091 | 20.144 |
| PresentMon CPU busy | 19.890 | 24.673 | 27.167 |
| GPU busy | 6.523 | 6.760 | 7.560 |

해당 16초 호스트 관측 64건 전부 게임 활성·노클립 OFF·비사망 296. 플레이어 위치 변화 0 UE 단위. 프로세스 CPU 시간은 약 2007ms/벽시계초(여러 스레드 합계)이며 프레임 시간이나 개체당 순수 비용이 아니다.

별도 시점 CPU 프로파일: 7.841초, 가중 표본 2584, 스택 연결 2572/누락 12, ETW 손실 0. 미분류 실행 파일 leaf 1531(59.25%), PhysX/APEX 라이브러리 leaf 92(3.56%), 그래픽 사용자 라이브러리 leaf 310(12.00%). 기존 앵커를 포함한 물리 inclusive union 95(3.68%), 접촉 소비자 inclusive 5(0.19%). Inclusive 범위는 중첩되며 NPC self-time이 아니다. 지지·낙하·등반 앵커 표본 없음은 비용 0의 증거가 아니다.

## 4. 원인 분석

확인: VSync 상태에서 실제 표시 간격은 약 20ms로 유지되었고 Present 호출 간격은 더 흔들렸다. 이는 전역 프레임 표시 관측이며 개별 본·애니메이션 시계의 부드러움 판정은 아니다. 기존 분석에서 접촉 버퍼 소비→지지 플래그·접촉 참조→낙하 이력 연결이 확인된 점은 재사용할 설계 참고다.

미확인: 애니메이션·밀침·지지 각각의 순수 비용, 현재 공유 포즈/LOD 실행 여부, 고비용 미분류 함수의 의미. 이번 표본만으로 Days Gone이 그 기능을 거의 무료로 처리한다고 말할 수 없다. 동시 수집 CSV가 WPR 시작 근처에서 끊겼지만 WPR이 원인이라는 인과는 입증되지 않았다. 표시 1차 CSV 미생성도 원인은 미확정이다.

DayZ 64와 개체 수·장면·해상도·VSync·실제 수행 작업량이 다르므로 배수 비교나 개체당 비용 환산을 하지 않는다. PresentMon의 AnimationError도 NPC 본 포즈 오차로 해석하지 않는다.

## 5. 검증 수준

진단 성공(유효 CPU 표본 + 표시 수집 각 1회). 반복 검증 완료·기능 회귀 통과·시각 품질 최종 수용·성능 최적화 성공은 아니다. DayZ 기능·64개체 비용 개선 결과도 아니다.

## 6. 변경 사항

현재 실행 빌드 SHA-256: `17c2fca01d566914147a6d4924d038cb1f5a822c2829e4c45862e2bf837730b3`. 수집 하네스에서 현재 창 ID 참조와 프로세스 핸들 유지/종료 확인을 국소 수정했고 표시 전용 출력 폴더를 분리했다. 기존 게임/서버/소스/PBO/원시 보고서를 변경하지 않았다. 서명 작업은 해당 없음.

## 7. 원시 증거

실행 ID: `dg-cost-debug-20261107-183622`; CPU `stationary-184457`, 유효 표시 `display-only2`, 제외 표시 `display-only1`. 공개 JSON에는 선별 요약과 상대 증거 ID·SHA-256만 포함한다. CPU/표시 원문은 로컬 보존하고 덤프·프로세스 식별자·로컬 절대 경로는 공개하지 않는다. 수집 도우미는 종료됐고 게임과 사용자 디버그 제어는 계속 실행 중이다.

## 8. 잔여 문제

현재 확보 자료만으로 DayZ에 옮길 새 최적화 구현을 정당화하지 못한다. 추가 전체 게임 계측을 반복하기보다 기존 접촉 버퍼 소비 구조와 DayZ Drive/Displace 소유 관계를 비교해, 동일 갱신 내 중복 접촉 처리의 소유자를 하나로 묶을 수 있는지 기존 기록에서 먼저 판단한다. 입력 완전 일치 0건이었던 과거 42쌍에 대해 무조건 캐시를 재도입하지 않는다. Days Gone 미분류 함수의 좁은 소유자 식별이 실제 개발 결정을 바꿀 때에만 제한된 추가 분석을 한다. 현재 결과는 비교 참고 자료이며 DayZ 주력 최적화를 대체하지 않는다.
