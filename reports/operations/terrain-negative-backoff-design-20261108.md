# 기존 물리 질의 연구 대조와 거절 인증 backoff 설계

## 1. 작업 목표

기존 물리 질의 최적화 실패 이력을 재사용해 중복 시험을 피하고, 현재 발 ray 약2.56만회/게임초를 줄일 수 있는 다른 후보의 최소 설계를 고정한다.

## 2. 실제 수행

Scratch, 지형 직접 조회, 지형 루프 분리, 관절 broadphase, SupportSweepFast, 표시 호스트 solid 기록과 현행 원본 SolveContacts를 읽었다. 작은 밀침 누적과 Drive/Displace 병합 기각 이력도 확인했다. 게임 실행/새PBO/실제 후보 구현 없이 설계와 입력 해시를 저장했다.

## 3. 측정 결과

새 측정0회. 기존 Scratch 국소1.5~2.5% 감소는5% 후속 기준 미달. 지형 통합/루프 분리는 평지 약48~50% 국소 감소, 일부 제외 경로3% 상한 초과. 관절 broadphase는clear+6.814%,blocked+26.672%로 미수용. 이 비율들은 다른 시험의 메서드 경과시간이며 합산/전체CPU 환산하지 않는다. 직전64solid 후보의 서버−3.03%/Presentp95+14.23% 미수용을 유지한다.

## 4. 원인 분석

기존 지형 후보는 비지형 인증이 거절되는 경로에서도 Overlap 등 추가 작업을 했다. 새 후보는 거절 후8회 SolveContacts에선 추가 인증 시도만 미루고, 원래 솔버를 매번 실행한다. 지지/충돌 성공 결과나clear 인증을 캐시하지 않는다. 안전성은 과거 결과가 아닌 해당 호출의 원래 검사가 담당한다. 추가 분기·위임 비용과 최적화 가용성 지연이 생길 수 있어 효과는 미확인이다.

## 5. 검증 수준

기존 이력 대조/설계 작성 완료. 구현·Enforce 컴파일·국소 비용·8/64기능·시각·성능 최종 수용은 모두 미실행이다. 제한된 체크포인트 검색에서 같은 negative certification backoff 기록을 찾지 못했으며 전체 과거 이력의 부재를 증명한 것은 아니다.

## 6. 변경 사항

기존 프로젝트의 격리 연구 위치에 DESIGN.md/design.json만 추가했다. 원본 소스·PBO·자산·서명·현재 기본 실행 경로는 변경하지 않았다. 새 서명 대상 없음. 이전 실패 후보를 수용으로 변경하지 않았다.

## 7. 원시 증거

설계 provenance에 사용한6개 체크포인트와 현행 Ground 소스의SHA256을 연결했다. 공개 JSON은 원시 경로 대신 파일명/해시만 사용한다. 기존 원시 로그·보고서는 보존했다.

## 8. 잔여 문제

다음 단일 산출물은 현행 packed 원본과 정합한 최소 후보 소스다. 기존 original/sham/terrain 시험 환경을 재사용해 첫 거절 비용·8회 fallback·blocked→clear 전환을 구분한다. solve횟수로 재시도해 frozen game time 때문에 전체블록이무료fallback되는 오류를 방지한다. 두 역순 독립 국소 시험의 평지5% 이득/각 제외경로3% 상한을 유지하며 미달이면8/64로 확대하지 않는다. 성공값 강제·양성 지지 캐시·논리 검사 삭제·애니메이션 틱 변경은 하지 않는다.
