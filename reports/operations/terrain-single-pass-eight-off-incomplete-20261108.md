# 8개체 OFF 비교 — 부분 관찰, 전체 판정 미완료

## 1. 작업 목표
같은 어댑터·장면·입력에서 OFF/ON 이동 기능을 비교한다.

## 2. 실제 수행
현재8개체·5표시파트·피해수신체와 훈련용 전투 설정을 양쪽에 준비했다. 최초 일반 서버에 진단 클라이언트를 잘못 연결해 SDK CLIENT_DIAG(0x00020017)가 발생했다. 진단 클라이언트를 닫고 기존 Steam 일반 클라이언트 경로로 수정했다. 보안 설정은 변경하지 않았다.

## 3. 측정 결과
OFF 부분 관찰140.755게임초. 낮은 발판 이정표8/8, 높은 발판7/8, 하강 관련 이정표1/8. 전체 하강 단계가 수행됐다는 뜻은 아니다. 1개체가 low/FOLLOW ENTRY_STALL_BACKOFF에 머물렀다. 관측된 피해 수신체는 모두 생존했고 모든 사용 로그에서 후보 OFF·후보 scope0·terrainSamples0이었다. CPU·p50/p95/p99·시각 수용 없음.

## 4. 원인 분석
초기 실행 종류 혼용은 실행 설정 오류다. 이를 수정하느라 최초430초 wrapper의 남은 시간이 게이트 시140.787초로 줄어 전체300초 관찰을 보장하지 못했다. 부분 관찰을 최종 기능 판정으로 쓰지 않는다. OFF 정체는 ON 회귀로 분류할 수 없다. 어댑터 없는 현재 기준 빌드에서 동일 재현은 이번에 확인하지 않았다. 복구 알고리즘 개발로 범위를 확대하지 않았다.

## 5. 검증 수준
등록된 서명 어댑터의 실제8개체 OFF 실행 확인. 전체 OFF/ON 기능 비교 미완료, ON 미실행. 이전 국소2회 gate 통과와 서명 성공은 원래 범위에서 유지한다. 전체 CPU·20ms·시각 성공은 아니다.

## 6. 변경 사항
관측용 미션·프로필·분석기·수정 실행 계획만 추가했다. 운영 코드·PBO 변경 없음. OFF 서버는 wrapper 시간 만료로 강제 종료됐으며 정상 퇴역이 아니다. 일반 및 실패 진단 클라이언트는 정상 닫기를 확인했다.

## 7. 원시 증거
ANIM-terrain-single-pass-eight1-off. partial-analysis/start-gate/server-terminal/client-closed/client-diag-closed/steam-launch-request 영수증과 원시 이동·사용 로그를 로컬 보존했다. 공개 요약에는 로컬 경로·프로세스 정보·원시 로그를 포함하지 않는다.

## 8. 잔여 문제
같은 미션/PBO를 유지한 eight2 계획에서 일반 서버+Steam 일반 클라이언트, wrapper600초·게이트 잔여310초 조건을 준비했다. 아직 실행하지 않았다. 현재8개체 기능 판정 전64 비용으로 확장하지 않는다. 실제 총기·근접·사망은 이 자동 이동 시험의 수용 범위가 아니다.
