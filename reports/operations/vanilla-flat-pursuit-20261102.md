## 2. 실제 수행

바닐라 ZmbM_CitizenASkinny_Blue의 AI·대상 선택·골격·충돌·포즈·갱신 정밀도를 수정하지 않고 별도 loopback 진단 서버/클라이언트에서 0→8→64→64→8 조건을 실행했다. 플레이어만 native input override로 원형 조깅하고 무적을 적용했다. static camera, 1600×900, VSync=1, client limitFPS60/server50, 같은 PC다. 커스텀 NPC 3종 PBO를 로딩하지 않았다.

새 모듈은 MissionGameplay에서 입력 자극·카메라·프레임 기록만 수행한다. PBO 원문 일치·서명·서명검증 통과. 두 실행에서 같은 모듈을 사용했다. 성능 도구는 기존 서명 유효 PresentMon2.6이며 관리자 principal과 대상 PID/생성시각/프로필을 검증했다. 서비스/권한그룹 변경·입력 추적·게임 native hook·영상 녹화는 없다. Computer Use로 실제 창/월드/군중을 확인했다.

준비 실패는 보존했다. 혼합 슬래시로 서명 도구/서버 config 경로 오류가 났고, mission expression도 컴파일에서 거부돼 수정했다. 이 시도들은 측정 실행으로 세지 않는다. 첫 성공 실행에서 과거 unused admin helper의 거부 기록과 정상 helper의 시작 기록이 겹쳐 monitor가 중단됐다. 실제 정상 tool의 대상/시작을 대조하고 workload를 나중에 시작했으며, 그 결과 마지막 8명 ETW가 짧아졌다. 이를 완전 반복으로 세지 않는다.

또한 첫 실행의 서버 telemetry가 의도4Hz 대신 약50Hz였다. 원본을 보존하고 두 번째 별도 프로필에서 샘플 gate를 명시 brace로 바꾼 mission만 사용했다. 두 번째 실제 빈도 약3.84Hz를 검증했다. 이 변경과 첫 실행의 높은 기록 부하 때문에 두 실행의 차이를 게임 최적화 개선률로 해석하지 않는다.

## 4. 원인 분석

확인: 바닐라 64개체의 이 평지·동일 모델·고정 카메라 조건에서 CPU frame-work와 GPU active 범위가 확보됐다. AI와 경로 이동이 실제 실행됐으며 단순 정지 모델64개가 아니다. 0명부터 비슷한 표시 주기가 있어 표시 간격 전체를 애니메이션 연산 시간으로 읽을 수 없다. frame-work는 전체 스레드 self-time이나 animation graph self-time도 아니다.

추정: 이번 조건은 CPU/GPU 처리 여유가 있어 보이지만, 동기화·대기와 VSync 제한이 섞여 정확한 무제한 처리량을 확정할 수 없다. 과거 커스텀 NPC의 p95약93ms와 직접 나눠 배수·개체당 overhead를 계산하지 않는다. 모델·카메라·AI·접촉·이동 시나리오·관측 부하가 다르다.

미확인: 개별 native animation graph/스키닝/본 업로드/GC self-time, 시각적 끊김의 시간적 품질, 카메라에서 동시에 그려진 정확한 개체 수/각 LOD. 64개체 존재/목표 기록이64개체 전부 최고LOD 렌더를 뜻하지 않는다. 스크린샷은 시간적 smoothness 증거가 아니다.

반증/정정: 첫 실행4Hz 가정은 실제 trace 빈도로 반박됐으며 주 결과에서 분리했다. 마지막8명30개 Present만으로 정상33초 반복이라 보고하지 않는다. 표시 p95≈20.1ms를 반올림해20ms 목표 달성으로 선언하지 않는다.

## 8. 잔여 문제

애니메이션만의 비용은 여전히 미측정이다. 다음 가치 있는 실험은 같은 평지·카메라·경로·시야·계측 주기로 커스텀과 바닐라를 대조하는 것이다. 이번 결과를 과거 다른 workload의 대조군으로 소급 적용하지 않는다. 무제한 처리 여유를 측정하려면 별도 프로필에서 VSync/프레임 제한만 통제하는 새 실험이 필요하지만 이번에는 사용자 디스플레이 설정을 변경하지 않았다. 정밀 animation 평가 비용과 실제 시간적 표시 진단은 계속 별도로 유지한다.

성공 시에는 비용 차이를 AI/접촉/모델/표시로 추가 분해하고, 조건 일치 실패 시 비교를 중단해 부하 차이만 기록한다. sampler OFF 대조 전에는 observer 비용을0으로 가정하지 않는다. 새로운 보간·LOD·검사 생략을 이 결과만으로 적용하지 않는다.
