# NPC 함수명 계측 후속 준비 — 실행 경로 미확정

## 1. 작업 목표
공식 EnProfiler로 현행 NPC의 소스 함수별 분포를 얻기 위한 8→64 진단 시험을 준비한다.

## 2. 실제 수행
기존 미션·수집기·SDK와 진단 실행기를 대조했다. 통합 어댑터 생성 명령은 자동 검토에서 실행 전 차단됐다. 원래 시험 폴더가 생성되지 않았음을 확인했다. 실행기와 보안 관련 인자를 수정하지 않는 검토용 계약·프로파일러 코드 조각만 별도로 저장했다.

## 3. 측정 결과
새 NPC 실행·계측 0회, 새 PBO 0개. 함수명별 실제 NPC 결과는 아직 없다. 기존 API 시험의 알려진 함수 50/50 확인은 유지한다.

## 4. 원인 분석
자동 검토는 `blocked by policy`만 반환했다. 구체적인 거부 이유는 미제공이며 보안·권한·명령 길이 등의 이유를 추측하지 않는다. 이 결과는 EnProfiler 자체나 엔진의 실패 증거가 아니다.

## 5. 검증 수준
계약·코드 조각 작성 완료. 미션 통합·컴파일·NPC 실행·기능·시각·성능은 미실행이다. 단일 API 시험을 실제 NPC 비용 귀속으로 확대하지 않는다.

## 6. 변경 사항
검토용 Markdown과 비활성 `.c.fragment`만 추가했다. 실행기·실행 인자·NPC·게임 PBO·애니메이션·서명·보안 설정은 변경하지 않았다.

## 7. 원시 증거
대화의 CreateProcess 사전 거부 결과, 원래 후속 폴더 부재 확인, NPC_OWNER_PROFILE_CONTRACT.md와 npc-owner-profiler.c.fragment를 연결한다. 거부된 명령을 다른 형식으로 우회 실행하지 않았다.

## 8. 잔여 문제
허용 가능한 진단 서버·클라이언트 실행 경로와 계측 미션 통합이 남았다. 기존 게임 코드나 보안 옵션을 바꾸지 않는 경로만 검토한다. 골은 미완료이며, 새 최적화 후보나 성과를 선언하지 않는다.
