# 접촉 후보64: 전체 CPU 선별 미수용

## 1. 작업 목표
군집 Update의 국소 반복 이점이 실제64개체 전체 서버CPU 감소로 연결되는지 단일 OFF/ON 선별. 기능/시각 수용은 별도.

## 2. 실제 수행
동일12서명PBO·미션·카메라·날씨, 활성화 플래그만 변경. 기존 Steam경로와 CPU수집기 재사용.2초 준비구간을 별도 보존하고40게임초 부근부터30벽시계초 측정. 수집 중 화면 캡처/입력 없음. 서버 퇴역·detach·RequestExit 뒤 actualexit-1, 강제 종료 없음. 클라이언트 정상닫기.

## 4. 원인 분석
후보 활성화와 기존 국소 비용 반복 이점은 확인됐으나 전체 CPU 차이는 작다. 세부 경로/접촉 작업량은 동일하지 않다.
접촉 분포 및 나머지 스크립트/네이티브 비용이 이점을 희석할 수 있으나 이번 자료로 개별 원인을 확정할 수 없다. 효과가0이라는 증거도 아니다.
단일쌍을 통계적 개선으로 보고하거나 국소28%를 전체CPU28%로 확대하지 않는다.
