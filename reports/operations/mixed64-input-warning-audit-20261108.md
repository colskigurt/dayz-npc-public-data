# 64개체 입력 동등성·기존 경고 재현 감사

## 1. 작업 목표

직전64개체 두 실행의 표시 경로 차이가 저장 설정/인자 변경으로 설명되는지 확인하고 기존 미해결 경고 연구와 중복을 점검한다.

## 2. 실제 수행

게임 재실행 없이 닫힌 그래픽 설정·실행 인자·Present CSV·RPT를 읽었다. 설정 파일 해시를 비교하고 실행별 프로필 경로만 정규화했다. 기존11월3일 부모 연결 계약 조사와11월5일 WARNING_AND_NEXT_TEST를 재사용했다.

## 3. 측정 결과

두 실행의 root/User 그래픽 cfg는 각각 같은 SHA256이다. 프로필 경로 외 실행 인자, DXGI, PresentFlags0, SyncInterval0도 같다. 실제 Present 모드/AllowsTearing은 다르다. 서버CPU는821.6193→826.8824ms/게임초(+0.6406%)의 두 관측이다. 최적화 차이가 아니다.

RPT의 outside-landscape 경고 총행은951937/715009다. 캡처 종료 wall시각에서 QPC길이를 뺀 약30.17/30.15초 범위에는288384/294144행, 약9558/9755행/초가 기록됐다. 이는 정확한 이벤트QPC join이 아닌 근사 시간대 집계다. 전체 파일은90.74/68.23MB다. RPT는 새로 생성하지 않고 기존 파일을 읽었다.

## 4. 원인 분석

설정/인자 차이라는 설명은 이번 저장 증거에서 지지되지 않는다. 드라이버·창·합성기의 일시 상태는 저장 설정만으로 배제할 수 없다. 표시 모드 변경 원인은 여전히 미확인이다.

반복경고는 새 발견이 아니라 기존 미해결 결함의 현재 재현이다. 이전 정지Run에서도 GroundBody 연결 없이 발생했으므로 Drive/Displace만의 문제로 단정하지 않는다. 기존 바닐라 네트워크 대조에는 같은 대량 반복이 없었다는 기록이 있다. 경고쓰기 CPU self-time, 실제 객체/자산/부모 참조 원인은 미확정이다. 이 경고가 현재 물리 병목이나 표시 모드 변경의 원인이라는 결론도 내리지 않는다.

## 5. 검증 수준

기존 자료의 입력 동등성 감사와 경고 동시 발생 확인: 진단 성공. 새 독립 실행0회. 수정/회귀/시각/성능 수용 아님. 현재64기준선은 이 미해결 경고를 포함하는 진단 조건이며 경고 없는 최종 품질 통과로 사용할 수 없다.

## 6. 변경 사항

분석 JSON과 보고서만 추가했다. 원시RPT·기존보고서·NPC·PBO·시계·물리·서명 변경 없음. 로그 억제/네이티브 패치로 문제를 숨기지 않았다.

## 7. 원시 증거

ANIM-mixed-gameplay64-baseline-retry2 / ANIM-mixed-gameplay64-repeat2. input-equivalence-audit.json, current-warning-audit.json 및 참조RPT 해시를 보관한다. 공개 JSON은 경고집계와 파일해시만 제공하며 로컬 경로/프로세스정보가 포함된 실행인자 감사는 내부 보존한다.

## 8. 잔여 문제

표시 경로 원인조사를 무한 확대하지 않는다. 같은 표시 모드의 실제화면 비교와 서버 CPU/work 비교를 구분한다. 기존 부모연결/경고 연구를 재사용하고, 다음 수정 후보가 이 경고/호스트 상태에 영향을 주는지 먼저 확인한다. 경고 CPU 기여가 측정되지 않은 상태에서 절감률을 제시하지 않는다. 전체 엔진분석·동일 실패시험 반복·새 기능개발로 최적화 주력을 바꾸지 않는다.
