# 클라이언트 설정 경로 불일치 진단

## 1. 작업 목표
첫 ETW 비교에서 요청 VSync=0과 실제 SyncInterval=1이 달랐던 설정 경로를 조사한다.

## 2. 실제 수행
기존 두 프로필의 루트 DayZ.cfg와 실행 후 생성된 Users/<runtime-user>/DayZ.cfg를 비교했다. 새 실행 없이 다음 시험 생성 도구가 관찰된 하위 사용자 설정 경로에도 동일 요청값을 쓰도록 수정했다. 기존 시험 파일은 수정하지 않았다.

## 3. 측정 결과
새 게임 실행 0회. 두 조건 모두 루트 VSync=0, 하위 사용자 파일 VSync=1. PostFX·FXAO·AnisoFilter·TerrainDetail·FXAA도 요청값과 저장값이 달랐다. 구문 검사·설정 생성/읽기·경로 이탈 입력 거부 3개 검증 통과. 이는 준비 도구 검증이며 실제 설정 적용 성공 판정이 아니다.

## 4. 원인 분석
확인: 저장 위치별 설정 불일치와 기존 ETW SyncInterval=1. 추정: 루트 설정이 실제 실행 설정으로 소비되지 않았을 가능성. 미확인: 엔진 내부 설정 선택 지점, 다음 실행의 VSync 적용 여부. 따라서 과거 조건을 VSync OFF 또는 요청 그래픽 품질의 실제 적용으로 표현하지 않는다. 두 조건의 하위 설정이 같았으므로 첫 비교를 폐기하지 않고 해당 조건의 단일 결과로 보존한다.

## 5. 검증 수준
정적 진단 성공. 런타임 수정 검증 미실행. 기능·시각·성능 수용 아님.

## 6. 변경 사항
tools/stage_palette64_client_trial_20261105.py: 관찰된 Users/<runtime-user>/DayZ.cfg에도 요청 설정 생성, 중첩 설정 파일 해시 수집, 다음 격리 실행 ID 5/6 허용. 사용자 경로 구성 검증 추가. 변경 전 도구와 해시 보존. 게임 코드·PBO 변경 없음, 새 서명 대상 없음.

## 7. 원시 증거
palette64-client-cost-preflight1/round4/config-path-diagnosis.json. 기존 eight4/five4 루트/하위 cfg 4개 해시와 값 포함. 실제 표시 계측은 이전 1쌍뿐이며 이번 문서 분석을 독립 반복으로 계산하지 않는다.

## 8. 잔여 문제
다음 단일 실험은 동일 씬에서 실제 소비 설정과 SyncInterval을 먼저 확인하는 제한된 비교다. 조건 적용이 확인되지 않으면 성능 반복으로 채택하지 않는다. 현재 5파트 후보는 미수용이며 대량 14클립 변환·기능 개발·전체 회귀 확대를 보류한다.
