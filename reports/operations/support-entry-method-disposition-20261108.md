# 진입 검사 재사용 비교 — 미채택

## 1. 작업 목표
TrySupportBypass 호출 내 동일 진입 검사 재사용 후보가 실제 경로·복구 결과를 보존하고 국소 비용 gate를 넘는지 확인한다.
## 2. 실제 수행
기존 월드 fixture·진단 서버 하네스를 이용했다. 평지/벽 근처/지붕/가장자리/낙하 조기반환/활성복구 조기반환의6조건,4방향,3그룹 반복,ABBA순서로 원본 복사와 후보를 비교했다. 각그룹 시작에 실제 원본 클래스까지 포함한 반환값·선택 경로 벡터·복구 및 계획 상태의 정확 비교를 수행했다. 총72그룹/288측정행,행당8메서드 호출이다. 실제 플레이 NPC는0개, 고정 시험용 host1개다. 상속받은 초기 plan의8논리 메타데이터는 method5에서0/host1로 명시 수정했다.
## 3. 측정 결과
288행 완료, 모든 비교 통과. 평지 rawTicks27072999→26243558(-3.0637%),벽 근처10692678→9818622(-8.1743%),지붕1868387→826248(-55.7775%),가장자리1076406→453739(-57.8469%). 낙하·활성복구 조기반환은 모두false 유지. 지붕/가장자리의 요청은 모두거절됐으며 이를 정상 등반 통과로 해석하지 않는다. 시간은 동일 하네스 rawTicks 상대 비교이고 CPU self-time·게임 프레임 시간이 아니다. p50/p95/p99·시각·8/64회귀 신규 측정 없음.
## 4. 원인 분석
반복 진입 검사의 지역 재사용은 대표 정적 월드 입력에서 원본 결정을 보존했다. 평지는 이후의 navmesh/path/segment 검사가 비용을 계속 차지하므로 전체 메서드 감소가작다. 이는 코드 구조에 근거한 해석이며 내부 함수별 시간 비율을 측정한 것은 아니다. 사전 gate의 평지5% 감소를 충족하지 못해 현재미채택. 큰 지붕 거절 개선만 선별해 성능 성공으로 보고하지 않는다. 독립 유효 프로세스1개이며3그룹 반복을3독립 실행이라고 세지 않는다.
## 5. 검증 수준
대표 정적 메서드 동등성 진단 통과, 단일 프로세스 국소 비용screen 실패. 반복 비용 검증 완료·8/64기능회귀·시각·최종수용 아님. 채택안함,64확장안함.
## 6. 변경 사항
격리 클래스와 하네스만 추가. 첫3실행은 각각 결과 변수 표현식/복잡 문자열 표현식/FileHandle 정리 문법으로 컴파일 실패했다.4번째는 하네스 카운터 누적 오류로 무효이며5번째만 유효다. 후보 알고리즘은 변경하지 않았고 실패파일을 보존했다. 컴파일 실패 서버는 별도 cleanup기록에 강제정리를 명시했다. 유효 실행은 정상종료 요청 뒤exit-1,강제종료없음. 운영코드/PBO/개인키/기존실행기 변경없음;신규서명대상없음.
## 7. 원시 증거

## 8. 잔여 문제
실시간 움직이는 월드에서의 동등성과 전체CPU 개선은 입증되지 않았다. 현재gate미달이므로 이를 입증하려고 긴8/64회귀를 시작하지 않는다. 다음은64명 진단의 고비용 Drive/ConsumeContact/Displace와 물리질의 소유자를 기존자료로 연결해 실제비용을 줄일 후보를 고르는 것이다. 정상 밀침·낙하·착지·추적·재등반을 보존하는 목표는 미완료이며 게임기능 복구 개발로 전환하지 않는다.
