# 64개체 비용 재시험: 측정 전 제외

## 1. 작업 목표
전용 측정 가능 답변 후, 원래 물리 검사와 5파트+receiver 구조를 유지한 timing-only OFF/ON 64개체 비용 비교를 재개하려 했다.

## 2. 실제 수행
기존 입력을 복사하지 않고 원본 PBO 13개·미션·seed를 참조한 새 실행 ID를 준비했다. 기존 실행기와 수집기를 사용해 첫 대조군 ANIM-ct64-retry1-1-control만 실행했다. 다른 게임이 실행 중이며 CPU를 쓰고 DayZ appActive=false가 지속돼, 비용 요청을 보내지 않았다. 사전 최대 client age90초가 지난 실제109.365초 상태를 확인하고 원래 retirement 경로로 종료했다. 사용자에게 다른 게임 종료를 요청했으며 임의로 종료하지 않았다.

## 3. 측정 결과
유효 CPU/Present 표본0, 신규 crash dump0. 대조군 timing/query 형식64/64 검증. 최종 누적 solves321406, foot rays3214060, joint sweeps1284616. 이 값은 비용이나 기능 성공률이 아니다. p50/p95/p99 미측정. 나머지5조건 미실행. 서버 RequestExit0 후 실제exit-1로 종료했으므로 normal exit 수용은 아니다. 강제 서버 종료 없음. 요청 없는 유휴 관리자 수집기만 신원을 검증해 별도로 정리했고, DayZ·서버·PresentMon·해당 수집기 종료를 확인했다.

## 4. 원인 분석
제외 원인: 측정 전제인 전용 부하·활성 화면이 실제 상태에서 충족되지 않았다. 이번에 크래시가 없었다는 사실은 이전 크래시 해결이나 observer 인과관계의 반증이 아니다. 실패한 실행을 재사용하거나90초 gate를 사후 완화하지 않았다.

## 5. 검증 수준
측정 전 제외. 기능 회귀·시각 품질·성능 개선 모두 미수용. 기존8개체 후보 단독 통과를64개체 성능 통과로 확대하지 않는다.20ms p95 목표 미달성 상태를 유지한다.

## 6. 변경 사항
재시험 계획·작은 기존 helper 스냅샷4개(총10669bytes)·collector config와 제외/정리 영수증만 추가. 게임 코드·PBO·모델·공용 실행기 변경 없음. 새 서명 대상 없음. 기존 실패·원시 기록 보존.

## 7. 원시 증거
ANIM-ct64-retry1-1-control의 pre-capture-exclusion.json, excluded-control-analysis.json, collector-idle-cancel.json 및 종료 server record를 해시 검증해 연결한다. 원시 script/RPT는 기존 실행 폴더에 보관한다. 공개본에는 로컬 경로·프로세스 식별자·개인키를 싣지 않는다.

## 8. 잔여 문제
다른 게임 종료 및 DayZ 전경 유지가 확인된 새 실행에서 비교를 재개해야 한다. 현재 실행은 제외 상태로 보존하고 재활용하지 않는다. 이전 native crash 원인은 미확정이며 재발 시 해당 비교와 후속 배치를 중단한다. 사용자 종료 답변을 기다리는 동안 새 클라이언트를 실행하지 않는다.
