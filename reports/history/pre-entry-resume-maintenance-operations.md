# 바탕화면 작업물 정리 검토함 준비

## 1. 작업 목표

사용자가 직접 정리할 수 있도록 바탕화면에 캐시·빌드 임시본의 위치와 검토 근거를 모으고, 다른 세션의 오래된 작업물을 접수할 구조를 준비한다.

## 2. 실제 수행

원본을 옮기거나 삭제하지 않고 바탕화면에 검토함을 만들었다. 00 사용 안내, 01 현재 검증 후보, 02 다른 세션 접수, 03 추가 검토, 04 보존·외장 보관, 90 근거로 구성했다. 32개 후보 폴더마다 파일별 CSV와 안내를 넣고 원본 위치 바로가기를 만들었다. 다른 세션 접수표와 개별 양식, 수동 처리 기록도 제공했다. 자동 삭제 스크립트는 포함하지 않았다.

## 3. 측정 결과

후보 361개 파일, 파일 크기 합계 4,486,454바이트(4.28MiB). 대상과 보존 소스 해시 재확인 361/361. 원본 폴더 32개 및 이전 정리 보고서 1개, 바로가기 총 33개를 생성하고 대상 경로를 확인했다. 검토판의 로컬 링크가 모두 존재하며 생성 파일 해시 manifest를 확인했다. 원본 이동·삭제 0건, 확보 공간 0바이트. 새 8/64개체 시험·프레임 시간·화면 측정은 없다.

## 4. 원인 분석

원본을 별도 폴더로 이동하면 실험의 절대경로 참조가 끊길 수 있으므로 목록·바로가기로 모았다. .build 전체는 삭제 가능한 캐시가 아니며 현재 소스와 전체 일치가 확인된 범위만 등록했다. 다른 세션 작업물은 아직 검증하지 않았고 접수 상태를 기본 미검토로 둔다. 삭제 이후 캐시가 재생성될 수 있으며 새 파일이나 변경이 생기면 재검토해야 한다.

## 5. 검증 수준

파일·보존 소스 대조와 바로가기 대상 검증 완료. 사용자 수동 정리·정리 후 동작 확인은 미실행. 앞선 자동 삭제는 정책상 차단되었고, 이번은 별도 요청에 따른 검토 인터페이스 제공이다. 자동 삭제를 다시 시도하지 않았다. 게임 회귀·화면 품질·성능은 이번에 측정하지 않았다.

## 6. 변경 사항

바탕화면에 TXT/CSV/JSON/HTML과 원본 위치 바로가기만 새로 만들었다. 게임 소스·PBO·서명·원시 실험과 과거 보고서를 변경하지 않았다. 새 게임 빌드 식별자는 없으며 서명 재실행 대상도 없다.

## 7. 원시 증거

로컬 바탕화면 검토함의 생성결과.json, 바로가기명세.json, 문서해시.json 및 기존 cleanup-064946/plan.json. 원본 위치·개인 환경 경로가 담긴 명세는 로컬에만 두고 공개본에는 집계만 제공한다.

## 8. 잔여 문제

사용자는 안내를 읽고 각 원본 위치에서 현재 파일 목록을 재확인한 뒤 휴지통 정리를 진행할 수 있다. 바로가기 자체를 지워도 원본 공간은 확보되지 않는다. 다른 세션은 접수표에 현재 사용 여부·보존 원본·재생성 절차·증거 참조를 기록하고 확인 전에는 원본을 이동·삭제하지 않아야 한다. 대용량 원시 기록의 외장 복사·복원 검증은 아직 수행하지 않았다. 실험 API 수치와 실험 시각을 갱신할 근거는 없다.
