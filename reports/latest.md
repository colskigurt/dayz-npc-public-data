# 실제64 격자 밀도 대조 — 국소 이득의 전체 비용 귀속은 미확인

## 1. 작업 목표
직전 상태 판정 재사용 후보의 밀집 국소20.57% 이득이 실제64에 연구 가치가 있는지 기존 로그만으로 판단한다. 기각된 일반 적용 gate를 사후 완화하지 않는다.

## 2. 실제 수행
기존 격자 재구성기의 load/snapshot 함수만 AST로 읽어 재사용했다. 최근 selective-peer-block-cost64-screen1 OFF/ON의 동일 게임시간10~60초에서 완전64행 표본을 분석했다. 원시 로그의 전후 SHA를 확인했다. PairCandidates/UpdateTicks 선언과 선택 미션의 Observe/OnUpdate 기록 경로를 읽었다. 새로운 게임·엔티티·PBO·영상은 없다.

## 3. 측정 결과
OFF 완전표본 188개, 격자 후보 평균 644.76, 범위 [194, 1228], 높이 통과 후보 평균 615.27. ON 186개, 평균 565.49, 범위 [156, 1106], 높이 통과 평균 531.22. 양쪽 모두 후보0 또는2016인 표본은0개다. 단계별 값은 existing-density1.json에 보존했다. 신규 p50/p95/p99·CPU·시각·8/64 기능 수치는 없다.

## 4. 원인 분석
확인: 기록된 실제 좌표 표본은 합성시험 양극단(후보0/2016) 사이였다. 희박 악화가 있었다는 이유만으로 실제64 이득을 반증할 수 없으며, 반대로 밀집20.57%를 실제 이득으로 확장할 수도 없다. 선택 로그에는 Crowd.UpdateTicks/실제 PairCandidates 시계열이 없다. Director.CrowdTicks는 선언돼 있으나 이것만으로 측정 실행을 입증하지 않는다.
추정: 중간 밀도에서 반복 상태 판정 감소가 도움이 될 수 있으나 관리 비용과 전체 CPU 기여는 알 수 없다. 높이 통과 수치는 Movable/전투/진입 우선순위/실제 힘을 포함하지 않아 ContactPairs가 아니다. OFF/ON 렌더 cadence가 달랐던 기존 코호트이므로 두 평균 차이를 성능 인과로 해석하지 않는다.
한계: 좌표가 반올림된 약0.25초 표본이며 실제 Update 시점의 후보 수가 아니다. 표본 비율을 전체 시간 비율로 사용하지 않는다. 기존 ETL interpreter 표본에서 이 스크립트 함수 self-time을 분리할 근거도 없다.

## 5. 검증 수준
기존 로그 재구성 진단 성공. 성능 개선·기능 회귀·독립 반복 검증·최종 수용은 미실행. 직전 일반 적용 비용 gate 실패는 유지한다. 원래 전체64 CPU 목표는 미해결이다.

## 6. 변경 사항
기존 crowd-eligibility-factor1 폴더에 재분석 스크립트와 JSON/보고서만 추가했다. 새 관리 구조나 원시 로그를 만들지 않았다. 원본 코드·PBO·실행기·지지·충돌·등반 재시도 불변. 신규 서명 대상 없음.

## 7. 원시 증거
ANIM-eligibility-existing-density1. 원본 두 gameplay-eight.tsv SHA와 재사용 분석기 SHA는 existing-density1.json에 보존한다. 이전 ANIM-crowd-eligibility-factor1 합성 시험과 별개이며 새 독립 게임 실행으로 세지 않는다. 기존 GRID_DENSITY_REVIEW.md의 재구성 한계를 그대로 적용한다. 공개본에 원시 로컬 경로·프로세스 정보는 포함하지 않는다.

## 8. 잔여 문제
현재 결정: 밀집 선택 캐시를 바로 구현하거나8→64 회귀로 확대하지 않는다. 전체 기여가 확인되지 않은 국소20%를 최적화 성과로 보고하지 않는다. 다음 최소 의사결정 실험은 기존64 기준 미션에서 이미 계산하는 Crowd.UpdateTicks와 Update 호출 수·쌍 수를 관측 간격마다 기록하고 같은 시계의 경과와 비교하는 것이다. 이는 경과 범위이며 순수 CPU self-time이 아니다. per-pair 타이머나 내측 로그를 추가하지 않는다. 한 번의 기준 짧은 장면에서 충분한 비중이 확인될 때만 중간 밀도/밀집 선택 후보의 국소 비교를 검토한다. 같은 자료로 이미 답한 밀도 분석이나 전체snapshot 실패는 반복하지 않는다.
