## 1. 작업 목표

기존 DayZ 구현·실험을 보존한 채 Days Gone 호드 실행 시스템과 DayZ를 실제 연결할 수 있는지 기존 자료로 판정한다. 전체 엔진 복원·신규 브리지 구현·게임 실행을 시작하는 요청으로 확대하지 않는다. 현재 64개체 CPU 최적화 연구는 별도 유지한다.

## 2. 실제 수행

기존 개체 관찰·호출 계측·경로 소비 정적 분석·노클립 소스와 결과, DayZ 커스텀 명령·파일 설정·네트워크 호스트 소스, 기존 CPU/도구 한계 보고서를 읽었다. 연결된 REA 6.7.0의 도구 목록과 대상 없는 binary_session 상태를 이번 대화에서 조회했다. 새 대상 import/attach/후킹/게임/PBO/모델 변경은 0회다.

검색 경계: 선정된 기존 파일과 Source/DGOriginalSample·network-body·PassthroughLab의 제한 검색이다. 호드 외부 제어 API·월드 주입 구현을 확인하지 못했다는 것은 해당 기능이 엔진에 절대 존재하지 않는다는 증명이 아니다.

### 권한과 데이터 계약 — 아직 설계·구현 아님

연결 전에 position/orientation/velocity/action/animationPhase/health/death의 최종 소유자를 하나씩 정해야 한다. DG와 DayZ 양쪽이 독립 물리로 같은 개체를 보정하면 위치 충돌·낙하 불일치가 생길 수 있다는 것은 설계 위험 추정이다. 어느 쪽을 끌지 지금 결정하지 않으며 정상 지지·밀침을 삭제하지 않는다.

기존 DG 좌표 자료와 노클립 코드는 Z 수직을 사용하고 DayZ 명령은 Y 수직 벡터를 사용한다. 정확한 스케일·부호·원점·yaw·부모 공간 대응은 별도 기준점 교정이 필요하다. 예를 들어 100배라고 지금 확정하지 않는다.

실시간 입력 계약 후보는 sessionEpoch, generation-checked actor ID, sequence, source simulation time, schema version, coordinate calibration ID, state owner, despawn/death, timeout 정책이다. 이것은 누락 항목 목록이며 이미 구현된 프로토콜이 아니다. CPU 벽시계와 시뮬레이션 시간도 구분해야 한다.

## 5. 검증 수준

기존 증거 대조: 문서 진단 성공(부분). 게임간 실시간 연결/독립 호드 실행/월드 교환/회귀/성능: 미실행. 기술 불가능 판정도, 결합 성공 판정도 하지 않는다. 추가 도구 확보를 기능 성공으로 보고하지 않는다. 기존 20ms 목표 미달성 판정은 유지한다.

## 6. 변경 사항

새 연구 검토 문서·선정 근거 패킷·공개 읽기 전용 요약만 추가한다. 기존 Source/PBO/서명본/모델/게임 설치본/원시 로그·실험 조건은 변경하지 않는다. 새 게임 빌드·서명 해당 없음. 기존 64개체 최적화와 실패 후보는 보존하며 이 검토로 최적화 골을 전체 엔진 복원으로 대체하지 않는다.

## 7. 원시 증거

선정 자료 ID: dg-tracks, dg-call-entries, dg-route-consumption, dg-readiness, dg-noclip-code/status, dg-property-registration, dg-cpu-report, dayz-command/control/network/ground, native-analysis-review, old-asset-conversion. 로컬 체크포인트 무결성 표에 파일 위치·크기·SHA가 연결된다. 공개 패킷에는 선정 위치/요약/해시만 제공하고 PID·절대 경로·포인터·원본 의사코드 전체·게임 자산을 내보내지 않는다. 각 요약은 발췌이며 전체 자료나 원본 코드 복원본이 아니다.

## 8. 잔여 문제

다음 단일 산출물 추천: B/C의 연결 입출력 계약표와 go/no-go 판정. 새 장시간 시험 전에 기존 자료에서 호드의 외부 목표 입력 후보와 DayZ의 지원 수신 경로를 한 쌍으로 제시해야 한다. 두 끝단이 특정되지 않으면 전체 엔진 분석으로 확대하지 않는다.

실행 실험을 하게 될 경우 첫 성공 기준은 고정 공통 장면 1개체의 식별자·시간·위치 전달과 명시된 목표 반응이다. 통과해도 임의 DayZ 지형 사용/64개체 성능/피격·낙하 소유권 통합 성공과 구분한다. 처음에는 영상이나 대형 덤프 없이 작은 상태/지연 기록으로 판정할 수 있다. 기존 자료로 목표 입력·월드 연결이 성립하지 않으면 '상태 재생만 가능 후보, 원본 AI 결합 미확보'로 종료하고 다른 방식을 검토한다.
